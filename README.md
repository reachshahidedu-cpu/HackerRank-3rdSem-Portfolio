# HackerRank 3rd Sem Portfolio

This repository contains my solutions to selected HackerRank algorithmic problem-solving challenges completed as part of my 3rd semester portfolio.

## Problems Solved

| Problem | Language | Time Complexity | Space Complexity |
|---|---|---|---|
| Diagonal Difference | C++ | O(N²) | O(N²) |
| Dynamic Array | C++ | O(N + Q) | O(N) |
| Time Conversion | C++ | O(1) | O(1) |
| Compare the Triplets | C++ | O(1) | O(1) |
| Sparse Arrays | C++ | O(N × Q) | O(N) |

## Reflection

Working on these HackerRank problems helped me improve my problem-solving skills and strengthen my understanding of arrays, strings, loops, vectors, indexing, and basic algorithmic techniques. I also learned the importance of considering time and space complexity while writing solutions. Organizing each problem in a separate folder and maintaining the work in GitHub helped me practice version control and documentation. This activity gave me practical experience in solving programming problems and presenting my work in a structured portfolio.
